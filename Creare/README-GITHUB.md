# 🎯 Creare Extension

Extensão Chrome para otimizar o trabalho na plataforma Creare (GoAwakeCloud).

## ✨ Funcionalidades

- 📋 **Copiar alertas** com emojis formatados
- ✍️ **Textos padrão** por tipo de tratativa
- 📧 **Grupos de emails** por operação
- 🔄 **Auto-update** via GitHub
- 🎯 **Auto-finalização** de tratativas
- 📹 **Captura de vídeos** do sistema
- ⚡ E muito mais!

## 🚀 Instalação

1. Baixe todos os arquivos deste repositório
2. Abra `chrome://extensions` no navegador
3. Ative o "Modo do desenvolvedor"
4. Clique em "Carregar sem compactação"
5. Selecione a pasta com os arquivos
6. Pronto! ✅

## 🔄 Sistema de Auto-Update

Esta extensão se atualiza automaticamente a cada 6 horas.

Quando uma nova versão é disponibilizada, você recebe uma notificação e pode atualizar com um clique.
