🚀 INSTALAÇÃO RÁPIDA (3 PASSOS)

1️⃣  ABRIR EXTENSÕES
   • Abra o Chrome
   • Digite na barra: chrome://extensions/
   • Pressione Enter

2️⃣  MODO DESENVOLVEDOR
   • Clique no botão "Modo do desenvolvedor" (canto superior direito)
   • Deve ficar AZUL/ATIVADO

3️⃣  CARREGAR EXTENSÃO
   • Clique em "Carregar sem compactação"
   • Selecione a pasta: maxtrack-whatsapp-extension
   • Pronto! ✅

═══════════════════════════════════════════════════════════════

📱 COMO USAR

1. Acesse: https://go.maxtrack.com.br/
2. Clique em uma linha da tabela de eventos
3. Clique no botão verde "Copiar para WhatsApp"
4. Cole no WhatsApp (Ctrl+V)

⚙️ CONFIGURAÇÃO INICIAL (IMPORTANTE!)

A extensão vem com seletores padrão que podem precisar de ajuste
conforme a estrutura real da tabela do Maxtrack.

🔧 PASSOS PARA AJUSTAR:

1. Acesse o Maxtrack e pressione F12
2. Cole o conteúdo de "teste-selectors.js" no Console
3. Execute: testarTodosSelectors()
4. Anote os índices/seletores de cada coluna
5. Edite "content.js" na seção SELECTORS
6. Recarregue a extensão em chrome://extensions/
7. Teste novamente com: testarSelectors()

📖 Detalhes completos em: GUIA-RAPIDO.md

🆘 PROBLEMAS COMUNS

❌ Botão não aparece
   → Aguarde 2-3 segundos após carregar
   → Recarregue com Ctrl+F5
   → Verifique console (F12) por erros

❌ "Nenhuma linha selecionada"
   → Clique em uma linha da tabela antes
   → Linha deve ficar destacada em verde

❌ Dados vazios ou incorretos
   → Seletores estão incorretos
   → Use teste-selectors.js para ajustar
   → Edite content.js e recarregue extensão

❌ Não copia para clipboard
   → Verifique permissões em chrome://extensions/
   → Use Chrome atualizado (88+)
